## Description
Operation Black Vault — Cryptography
Challenge: Single Vector
Difficulty: 🟢 Easy

A classified document was encrypted using a faulty logic gate. The system applied a single-byte XOR mask, but to be "safe," the engineer also ran it through a custom substitution cipher and Base32 encoding.

We recovered the `encrypt.py` script from their system along with the `encrypted_doc.bin` file.

Reverse the process and recover the flag.
