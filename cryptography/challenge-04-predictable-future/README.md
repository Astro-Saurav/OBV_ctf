# 4 Predictable Future

**Category:** Cryptography
**Difficulty:** 🟡 Medium

## Description
Operation Black Vault — Cryptography
Challenge: Predictable Future
Difficulty: 🟡 Medium

The vault's electronic lock generates access tokens using a custom pseudo-random number generator (a Linear Congruential Generator). We observed a few sequential tokens. 

The flag is XOR'd against a keystream generated by this LCG (starting from the 4th token). The resulting ciphertext was then encrypted again using DES-ECB with a hardcoded key found in the source. 

Decrypt the DES layer first, then predict the LCG's state to reverse the XOR and unlock the vault.
